# AGO P1 local workforce: dedicated project manager and discovery worker

This is designed for Founder private localhost use. It does NOT repair or replay
the previously attempted original discovery task. Existing project leader or
approvals are immutable under this helper.

## Why the old repair was blocked

The recorded project lead can be a human Founder, AI Board CEO, or the same
employee as the task worker. None meets the current *seven distinct AI roles*
requirement. Do not change a human's kind or forge a manager link.

## Setup

Keep the AGO server running in `-Engineering` mode. Use another PowerShell:

```powershell
cd C:\Users\rudra\Projects\ago-
python .\scripts\ago_project_team_setup.py --create-missing
```

This is a no-write inspection of the existing AI CEO, any canonical project
manager and independent analyst identities.

After verifying the exact officers and duties, explicitly choose:

```powershell
python .\scripts\ago_project_team_setup.py --create-missing --apply
```

The Founder must type `CREATE_SEPARATE_AGO_PROJECT_TEAM`.
The final readback confirms two real, distinct AI employee records, PM reports
to CEO, and Discovery Analyst reports to PM. No local LLM inference is started.

In local seven-role engineering mode, **new** founder project intakes prefer an
existing distinct AI Project Manager reporting to the five-seat Board CEO as the
accountable project manager; previously created founder projects remain unchanged.

To run any new discovery task, create a new Founder brief with its own approvals
through the Company Map. Do not replay task
`f0f990f6-d823-43a2-8e66-54bd3f5f23cb` (original attempted task).

If an existing AI employee already has another manager, the setup refuses to
silently change it. Review in the Company Map and make a new explicit decision.
